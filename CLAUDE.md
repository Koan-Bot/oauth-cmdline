# CLAUDE.md — OAuth::Cmdline

## What is this project

OAuth::Cmdline is a CPAN module (Perl) that handles OAuth2 authentication for
command-line applications using web services. It provides a base class with
site-specific subclasses for Google Drive, Spotify, YouTube, Microsoft Online,
Smartthings, and Automatic.

- **Author**: Mike Schilli (upstream: `mschilli/oauth-cmdline`)
- **Fork**: `atoomic/oauth-cmdline` (PR target), `Koan-Bot/oauth-cmdline` (origin)
- **License**: Perl 5

## Build system

- **Dist::Zilla** (`dist.ini`) is the build/release tool. Do NOT edit `Makefile.PL`
  directly — it's auto-generated by dzil.
- `cpanfile` declares runtime and test dependencies.
- Minimum Perl version: **5.16** (required by Mojolicious).
- Adding `use 5.016;` to a module is the proper way to enforce min Perl
  (not editing Makefile.PL).

## Code structure

```
lib/OAuth/Cmdline.pm          # Base class (Moo). Token lifecycle, cache, HTTP helpers.
lib/OAuth/Cmdline/
  GoogleDrive.pm              # Google Drive subclass
  Spotify.pm                  # Spotify (uses Basic auth for token refresh)
  Youtube.pm                  # YouTube
  MicrosoftOnline.pm          # Azure AD (requires `resource` attr, rotates refresh_token)
  Smartthings.pm              # Smartthings (auto-configures endpoints from base_uri)
  Automatic.pm                # Automatic.com (redirect_uri returns undef)
  CustomFile.pm               # Custom credential file path
  Mojo.pm                     # Mojolicious app for the OAuth callback flow
  templates/                  # Mojo HTML templates
t/                            # Tests (Test2::Bundle::Extended)
eg/                           # Examples
```

## Key patterns

- **Moo** for OOP. All subclasses use `extends 'OAuth::Cmdline'`.
- **Cache files** stored as YAML in `~/.{site}.yml`, written with `umask 0177`.
- **Token refresh**: base class handles standard OAuth2 refresh. Subclasses can
  override `token_refresh_authorization_header()` (Spotify) or
  `update_refresh_token()` (MicrosoftOnline).
- **Expiration threshold**: token considered expired when `< 300` seconds remain.
  Exactly 300s = not expired.
- **`http_get`**: convenience method. Known bug on master: passes `@$query` both
  as URI query_form AND as extra args to `$ua->get()` (extra args become HTTP
  headers). Fixed in PR #9.

## Testing

```bash
prove -vl t/*.t
```

- Tests use **Test2::Bundle::Extended** + **Test2::Tools::Explain**.
- Unit tests use `File::Temp` for isolated cache files. No external service calls.
- Live integration tests are gated by `LIVE_TESTS` env var — use `SKIP` blocks,
  not `plan skip_all`.
- Current test files: `001Spotify.t`, `002Smartthings.t`, `003MicrosoftOnline.t`.

## Known architecture notes

- `MIME::Base64` is imported in the base class but only used by Spotify.
- `tokens_get` error handler has a known bug (comma-as-separator making `$data`
  assignment part of DEBUG args) — fixed in open PRs.
- `LWP::UserAgent->new()` without timeout can hang forever on dead endpoints.
